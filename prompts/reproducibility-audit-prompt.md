# 复现性审计提示词
# Reproducibility-Audit Prompt

请检查论文是否提供原始数据、处理后数据、代码、环境版本、随机种子、超参数、训练检查点和运行命令。

Check whether the paper provides raw data, processed data, code, environment versions, random seeds, hyperparameters, training checkpoints, and execution commands.

请区分“理论上可复现”“代码可运行”“结果数值可复现”和“生物学结论可独立验证”四个层次。

Distinguish four levels: theoretically reproducible, code executable, numerical results reproducible, and biological conclusions independently verifiable.

请指出最可能导致复现失败的五个环节，并按影响和修复成本排序。

Identify the five stages most likely to cause reproduction failure and rank them by impact and repair cost.

请生成一个最小复现实验，明确输入、预期输出、成功标准和停止条件。

Generate a minimal reproduction experiment with explicit inputs, expected outputs, success criteria, and stopping conditions.
