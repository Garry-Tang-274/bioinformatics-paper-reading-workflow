# 图表分析提示词
# Figure-Analysis Prompt

对每张关键图，先解释横轴、纵轴、颜色、分组、样本单位、误差线和统计标记。

For each key figure, first explain the x-axis, y-axis, colors, groups, sampling unit, error bars, and statistical annotations.

随后说明图想回答什么问题、使用了什么对照、观察到什么模式，以及该模式是否足以支持图注或正文中的结论。

Then state the question addressed by the figure, the controls used, the observed pattern, and whether that pattern is sufficient to support the conclusion in the caption or main text.

若图中比较多个模型，请记录参数规模、输入信息、训练数据和调参预算是否可比。

If the figure compares multiple models, record whether parameter counts, input information, training data, and tuning budgets are comparable.

若图中没有展示不确定性、样本量或统计检验，请明确标记为证据缺口，而不是假设其存在。

If uncertainty, sample size, or statistical testing is not shown, mark it explicitly as an evidence gap rather than assuming it exists.
