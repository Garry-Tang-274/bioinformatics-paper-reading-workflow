# 复现性检查清单
# Reproducibility Checklist

- [ ] 原始数据和处理后数据是否可获得？
- [ ] Are raw and processed data available?
- [ ] 代码许可证和依赖版本是否明确？
- [ ] Are the code license and dependency versions clear?
- [ ] 是否记录随机种子与硬件？
- [ ] Are random seeds and hardware recorded?
- [ ] 是否提供完整预处理和划分代码？
- [ ] Are complete preprocessing and split-generation scripts provided?
- [ ] 是否能从空环境执行最小示例？
- [ ] Can a minimal example run from a clean environment?
- [ ] 关键表格或图能否由代码重新生成？
- [ ] Can key tables or figures be regenerated from code?
