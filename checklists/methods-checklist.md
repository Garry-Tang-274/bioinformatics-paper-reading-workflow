# 方法学检查清单
# Methods Checklist

- [ ] 研究问题和主要终点是否预先定义？
- [ ] Were the research question and primary endpoint defined in advance?
- [ ] 样本单位是否与统计检验单位一致？
- [ ] Does the sampling unit match the statistical-testing unit?
- [ ] 对照是否能排除最主要的替代解释？
- [ ] Can the controls rule out the main alternative explanation?
- [ ] 模型比较是否使用相同输入信息与调参预算？
- [ ] Do model comparisons use the same input information and tuning budget?
- [ ] 误差线、重复次数和统计检验是否完整报告？
- [ ] Are error bars, replicate counts, and statistical tests fully reported?
- [ ] 消融实验是否真的隔离了目标模块的作用？
- [ ] Do ablation studies truly isolate the target module’s contribution?
